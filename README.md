# CHESAKL ToolFlow

Простой статический сайт для выдачи и возврата инструмента по NFC.

## Как запустить на GitHub Pages

1. Создайте новый публичный репозиторий.
2. Загрузите в корень все файлы из архива.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Нажмите **Save**.
6. Откройте выданный GitHub Pages адрес в Chrome на Android.

## Как пользоваться

1. В настройках добавьте сотрудников и инструменты.
2. Запишите на NFC-метку обычный текст:
   - сотрудник: `EMP-001`
   - инструмент: `TOOL-001`
3. На главной странице нажмите **Сканировать NFC**.
4. Приложите карту сотрудника.
5. Приложите метку инструмента.

Если инструмент свободен — он будет выдан.
Если он уже числится за этим сотрудником — он будет возвращён.

## Важно

- Web NFC работает в Chrome на Android и только через HTTPS.
- Данные хранятся локально на конкретном телефоне/планшете.
- Для работы на нескольких устройствах понадобится серверная база данных.
- Делайте резервную копию через раздел «Настройки».


## Новый режим списка

1. Сотрудник прикладывает свою NFC-метку — список открывается.
2. Затем подряд сканирует все инструменты.
3. Каждый инструмент сразу выдаётся или возвращается.
4. Сотрудник повторно прикладывает свою NFC-метку — список закрывается.


## Рекомендуемое название репозитория

`chesakl-toolflow`


## Работа через URL-метки

Для сотрудника записывайте URL вида:

`https://anatolii-gif.github.io/chesakl-toolflow/?tag=EMP-001`

Для инструмента:

`https://anatolii-gif.github.io/chesakl-toolflow/?tag=TOOL-001`

Удобнее открыть раздел «Настройки» и нажать «Скопировать ссылку» рядом с нужным сотрудником или инструментом.

Сценарий:
1. Метка сотрудника открывает его список.
2. Метки инструментов подряд выполняют выдачу или возврат.
3. Повторная метка сотрудника закрывает список.
